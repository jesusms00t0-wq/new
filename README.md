# Sky Hop

A polished, responsive Flappy Bird-style browser game built with vanilla HTML, CSS, and JavaScript.

## Play

Open `index.html` in a browser. Tap the game, click, press **Space**, or press **Arrow Up** to flap.

## Run with Node.js

No packages are required. From the project directory, run:

```bash
node server.js
```

Then visit <http://localhost:3000>. Set the `PORT` environment variable to use a different port.

Alternatively, serve the folder with Python:

```bash
python3 -m http.server 8080
```
