# Sky Hop

A polished, responsive Flappy Bird-style browser game built with vanilla HTML, CSS, and JavaScript.

## Play

Open `index.html` in a browser. Tap the game, click, press **Space**, or press **Arrow Up** to flap.

You can also serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit <http://localhost:8080>.
